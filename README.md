# mathdrill 🧮

口算练习小游戏：随机出四则运算题，计时、记分、统计正确率，还有错题回顾。

标准库 only，零依赖。

## 玩法

```bash
python -m mathdrill            # 交互模式：10 道题
python -m mathdrill --ops +-   # 只练加减法
python -m mathdrill --ops "x/" # 只练乘除法（x、/ 是别名）
python -m mathdrill --digits 2 --count 20   # 2 位数，20 道题
python -m mathdrill --auto     # 自动演示（无需输入，用于测试）
```

参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `--ops` | 运算符，可用 `+ - × ÷`（别名：`x * X`→×，`/ :`→÷） | `+-×÷` |
| `--digits` | 数字位数（1–3） | `1` |
| `--count` | 题目数量（≥1） | `10` |
| `--auto` | 自动演示：奇数题答对、偶数题答错 | 关闭 |

## 出题规则（写在代码里，家长可放心）

- **除法必整除**：先随机定除数和商，再相乘得到被除数，永远不会出现除不尽。
- **减法不出现负数**：被减数小于减数时自动交换，适合小朋友。
- 题目用 `random` 生成；`--auto` 用固定种子 `42`，演示结果可复现。

## 评分

- 每题答对 +1 分；最后显示得分、正确率、总用时、平均每题用时。
- 非法输入（字母、空回车等）会提示并记为错误，不会崩溃。
- 正确率 ≥ 90% 会获得「🌟 口算小达人！」称号。

## 已知限制

- 除法被除数是"除数 × 商"算出来的，`--digits 3` 时被除数最多可达 6 位数，读题稍费眼。
- 题目不查重，偶尔会出现重复的题。
- 没有做排行榜/存档，每次成绩只显示在当次会话里。
